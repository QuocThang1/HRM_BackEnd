# Human Resource Management (HRM) System - Backend

**Project Timeline:** 08/2025 - 11/2025

**Frontend Repository:** https://github.com/QuocThang1/HRM_FrontEnd

## Overview
This repository contains the backend source code for the Human Resource Management (HRM) System. It acts as the secure core of the application, responsible for complex business logic, database interactions, user authentication, and third-party AI integration for automated CV screening.

## Technologies Used
* Node.js
* Express.js
* MongoDB
* RESTful API
* JWT (JSON Web Token)

## Key Features
* **RESTful APIs:** Robust and scalable API endpoints to handle CRUD operations for internal management modules (employees, tasks, payroll).
* **Security & Authentication:** JWT authentication implementation to secure routes and manage role-based data access.
* **Automated CV Screening:** Direct integration with Gemini AI to analyze candidate CVs, significantly reducing manual review time.
* **Database Management:** Structured MongoDB schemas to efficiently store and manage complex operational data.
